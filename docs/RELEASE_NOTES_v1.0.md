# Known Limitations

## Image Generation

AI image models may misinterpret:

- temporary construction objects
- complex real-world scenes
- hidden geometry

Best results are achieved using structured CAD/BIM data.


## Runtime

ComfyUI runtime must be available for image generation workflows.
